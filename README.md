# SkicaCAD (Beta 0.71)

Parametrické 3D CAD v prohlížeči – instalovatelná PWA (funguje i offline po první návštěvě online).
Aktuální verze je v souboru `version.js` (jediné místo, kde se verze mění). 

## Ukládání návrhů
Návrhy se ukládají automaticky jen v prohlížeči daného zařízení (localStorage, importované modely v IndexedDB).
Zálohu celé knihovny uděláte přes Soubor › Zálohovat knihovnu (.zip) a obnovíte ji přes Soubor › Obnovit knihovnu ze zálohy – i na jiném zařízení.
